# Pressastra

Pressastra 是一款面向 WordPress 站长的 Windows 桌面工具箱，帮助你更轻松地完成内容发布、数据备份与站点日常维护。

## 下载与安装

1. 前往 [Releases](https://github.com/xuxk-cn/Pressastra/releases) 下载最新版压缩包。
2. 解压到任意目录。
3. 双击 **Pressastra.exe** 启动。
4. **Pressastra-Runner.exe** 是主程序调用的工具运行器，请与主程序保留在同一目录，无需单独运行。

无需安装 Python 或其他开发环境。

## 主要功能

### 内容发布
- Markdown 单篇发布与项目目录批量发布
- 支持分类、特色图片、草稿状态与预演模式

### 备份与迁移
- 数据库 SQL 导出与恢复
- 全站内容、媒体文件与清单导出/导入
- 支持将内容迁移到另一 WordPress 站点

### 内容管理
- 文章标题与摘要编辑，支持更换特色图片
- 文章列表分页浏览
- 页眉、页脚与菜单编辑
- 首页布局与置顶文章管理

### 媒体工具
- 文件夹图片批量导入媒体库
- 图片压缩与尺寸裁切
- 重复图片检测、勾选与清理

### 站点连接
- 支持通过浏览器完成 WordPress 应用密码授权
- 登录凭据保存在本机 Windows 凭据管理器中

## 免费试用与授权

- 首次启动自动获得 **14 天免费试用**，无需输入授权码。
- 试用期间全部功能可用。
- 到期后需要输入授权码继续使用。
- 授权码购买与售后请通过官方销售或客服渠道获取。

## 首次运行提示

如果 Windows SmartScreen 弹出提示，请先核对 Release 页面公布的 SHA256 校验值，再选择“仍要运行”。

## 使用说明

1. 填写你的 WordPress 站点地址、用户名和密码（或应用密码）。
2. 点击登录。
3. 选择需要使用的工具。

你的站点地址、账号与密码由你本人填写；安装包不包含任何预置站点凭据。
